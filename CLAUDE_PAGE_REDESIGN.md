# Итог переработки продуктовой страницы Claude

Дата завершения: 22 июля 2026 года  
Боевая страница: https://www.gptishka.shop/claude

## Результат

Страница переведена с набора разрозненных карточек и тяжёлого видеофона на цельную редакционную продуктовую страницу. Сохранены общий хедер, футер, модальное оформление заказа и получение тарифов из публичного API.

Новая последовательность блоков:

1. Первый экран с ясным оффером, ценой от API и одним основным действием.
2. Короткая строка доверия.
3. Три тарифных сценария: Pro, Max 5x и Max 20x.
4. Что получает покупатель.
5. Возможности Claude.
6. Четыре шага подключения.
7. Условия, поддержка и правовая информация.
8. Доступный FAQ.
9. Финальный призыв к действию.

## Что изменено

- Удалён autoplay-видеофон; вместо него используется лёгкий статичный постер.
- Убраны четыре лишних общих CSS-подключения, визуальные эффекты шума и размытия для этой страницы.
- Второстепенные информационные блоки больше не оформлены как одинаковые карточки; карточочная модель оставлена только тарифам.
- Тарифный конструктор выводит ровно три уникальных предложения из API.
- Исправлена связь карточки с вариантом тарифа в checkout: выбранный Max 5x открывается как Max 5x, Max 20x — как Max 20x.
- Статический первый экран не перезаписывается динамическим шаблоном после ответа API.
- FAQ синхронизирует визуальное состояние с `aria-expanded`.
- На странице Claude отключён невидимый фоновый опрос тикера.
- Добавлены адаптивные состояния для 960, 720 и 420 px, видимые focus-состояния и поддержка `prefers-reduced-motion`.

## Проверки

- Боевая цена первого экрана: `1 999 RUB`.
- Боевые тарифы: Pro — `1 999 RUB`, Max 5x — `10 999 RUB`, Max 20x — `22 299 RUB`.
- Проверен checkout для Max 5x: заголовок и итоговая сумма соответствуют выбранной карточке.
- Модальное окно закрывается по Escape и возвращает фокус кнопке покупки.
- FAQ раскрывается и корректно обновляет `aria-expanded`.
- На ширине 360 px горизонтального переполнения нет.
- JavaScript-файлы прошли `node --check`.
- Девять серверных тестов прошли; пять существующих тестов вне страницы Claude остаются красными из-за устаревших ожиданий CSP/версии бандла, отсутствующего VPN-маршрута и экспорта тикера.
