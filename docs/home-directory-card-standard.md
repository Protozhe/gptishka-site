# Стандарт карточек каталога на главной

Карточки сервисов в секциях «Нейросети» и «Пополнения» используют компонент
`.ai-directory-card` с обязательным модификатором
`.ai-directory-card--integrated`.

## Зафиксированный внешний вид

- Внешний контейнер является частью общего фона страницы: без собственной
  заливки, рамки, тени, blur и внешнего скругления.
- Изображение остаётся самостоятельным квадратным элементом с обрезкой по
  скруглению контейнера (`aspect-ratio: 1 / 1`, `overflow: hidden`).
- Основное и hover-изображение занимают одну геометрию и переключаются только
  через opacity, без изменения размеров карточки.
- Текстовый блок находится в обычном flex-потоке. Нижний блок прижат вниз через
  `margin-top: auto`.
- Кнопка имеет ширину ровно как у изображения: у body и bottom отсутствуют
  горизонтальные padding.
- Hover карточки меняет кнопку целиком: фон, цвет текста, border, внешнюю тень,
  внутренний highlight и focus-outline.

## Добавление нового товара

Новые AI-сервисы, создаваемые через `renderAiDirectoryCard()`, автоматически
получают `.ai-directory-card--integrated` и стандартную зелёную тему. Для
индивидуального оформления добавьте модификатор темы и переопределите только:

```css
.home-wide-page .ai-directory-card--service-key {
  --directory-button-hover-bg: linear-gradient(...);
  --directory-button-hover-border: ...;
  --directory-button-hover-shadow: ...;
  --directory-button-hover-color: ...;
  --directory-button-focus: ...;
}
```

Подпись кнопки должна оставаться внутри
`.ai-directory-card__button-label`, чтобы она располагалась над анимированным
псевдоэлементом. Если исходное изображение содержит прозрачные поля, масштаб
корректируется только индивидуальным модификатором изображения, а не общей
геометрией компонента.

Перед публикацией необходимо проверить desktop и mobile, равенство ширины
media/button, оба изображения и focus-visible.
